# dxFeed Graal Native SDK headers

The C headers of the [dxFeed Graal Native SDK](https://github.com/dxFeed/dxfeed-graal-native-sdk) release pinned in
[internal/sdk/sdk.go](../../sdk/sdk.go), copied unchanged from its release archive. They are distributed under the
Mozilla Public License 2.0, see [LICENSE](LICENSE).

To update the SDK, replace these headers with those of the new release and change the version and the archive
checksums in `internal/sdk/sdk.go` in the same pull request.
